More notices for ONNX Runtime

Code inside libonnxruntime.so (ONNX Runtime 1.28.2, commit 33ca9628233dc8f002435e868d4c2e9f82766ca1) whose notices are not in Microsoft's third-party notices file for that release. Microsoft's file is the separate entry "Libraries inside ONNX Runtime"; it also covers the XNNPACK-derived fp16 kernels (activate_fp16.cpp), the Pillow resampling filters and the Hugging Face beam search.
